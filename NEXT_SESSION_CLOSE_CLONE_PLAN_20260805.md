# AlienTAI Next-Session-Close Clone Family

Status: `COMPLETE_RESEARCH_HOLD` (August 6, 2026)

This plan creates six new models from the current promising-model list while
leaving every source model, hash, journal, outcome, cutoff, and report
unchanged.

## Frozen target change

Only the exit horizon changes. Each clone preserves its source model's:

- universe;
- point-in-time feature families;
- decision timestamp;
- executable entry convention;
- maximum selection count; and
- 0.25% round-trip cost assumption.

The new exit is the official close of the next complete regular market
session after the model's source decision. Daily-close and pre-open models
therefore target the next open-to-close session. The intraday AI/semi calls
clone preserves its intraday entry and exits at the close of the following
complete regular session.

## Why new training is mandatory

Model weights and score thresholds learned for five, twenty, or sixty-minute
horizons cannot be relabeled after training. Every clone needs a new
point-in-time label, chronological partitions, horizon-appropriate purging,
validation-only policy selection, and an independently sealed test.

## Existing reusable evidence

The AI/semi archive already contains a one-session
technical+premarket+calls analog. Its validation-locked historical test
contained 37 selections, a +0.461784% average net return, +0.539776% median,
and 54.05% positive observations after the 0.25% cost. This is exploratory
evidence only and does not replace the required isolated clone or future
journal.

## Execution order

1. Validate every source artifact and immutable feature list.
2. Build exact one-session labels without overwriting a source panel.
3. Train each clone into a new empty model root.
4. Choose cutoffs or basket fractions using validation only.
5. Open a sealed test once only when the validation gate passes.
6. Freeze passing artifacts into separate append-only prospective journals.

No clone is authorized for paper or live trading.
